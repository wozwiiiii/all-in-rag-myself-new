## 一句话数据速览（本人实测，2026-09-03 更新）

- 索引：15 篇文档 / 710 分块（含 OCR 兜底新增 4 篇扫描版 PDF）
- 表格：17 张 parquet，最大单表 26 万行
- 评测：18 题四类（text 8 / table 6 / hybrid 2 / refuse 2），已补 16 题 `reference` + 18 题 `expected_route`，指标语义权重生效后总分进入 0.94~0.96 区间
- 测试：**172 项全绿**（含 30 条沙箱攻击载荷；评测口径 v2 含事实一致性维度）
- 检索：三路融合后关键词证据完备度 100%（诊断脚本逐题验证）
- 服务：REST + SSE 流式双接口（`/qa` 与 `/qa/stream`），带认证限流、usage 观测、输入侧注入防护
