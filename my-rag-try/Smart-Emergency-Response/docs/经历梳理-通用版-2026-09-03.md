## 项目经历 · Smart-Emergency-Response · 独立开发

> 基于 Datawhale 秋训营赛题的本地化复现与工程化优化，面向危化品应急管理场景的混合问答服务（RAG 文本检索 + Text-to-Pandas 表格代理）。

### 简历表述（可直接粘贴）

- 独立设计并实现混合问答系统，构建 **RAG 文本检索（向量 + BM25 + rerank 三路融合）** 与 **Text-to-Pandas 表格代理（ReAct 两阶段 + 子进程安全沙箱）** 双链路，由 LLM 意图路由分发、hybrid 双路并行融合，覆盖 20 篇法规语料（15 篇入索引）与 17 张业务表（最大单表 26 万行）
- 为表格代码生成设计 **三层安全沙箱**（AST 静态白名单 + curated 运行时命名空间 + 子进程隔离超时强杀），30 条攻击载荷全部拦截，从黑名单演进到白名单（红队驱动）
- 建立 **评测闭环**：自建 18 题评测集 + 诊断脚本，发现并修复"评分指标语义权重失效"问题——补 `reference` 后单题天花板从 0.85 恢复至 1.0，总分从 0.867 提升至 0.96 区间；主动识别出"指标只测覆盖、不测正确性"的盲区
- 补齐生产级能力：**token usage 可观测**（线程安全累加器）、**SSE 流式输出**（首事件 <1s）、**输入侧 prompt 注入防护**（结构隔离 + 输出检测）；测试 **120 项全绿**

## 面试叙事建议（通用版）

**最能打动面试官的一条主线**：不是"我加了 BM25 / 沙箱"，而是「我发现自己的评测指标饱和失效了，然后诊断、修复、重新验证」——体现度量意识与自我证伪能力，这是区别于同龄人的判断力层级。

**建议叙事顺序**（30 秒自我介绍 + 追问展开）：

1. 一句话定位：赛题复现起步，做到可上线的工程化版本
2. 双链路架构 + 安全沙箱（技术硬点）
3. 评测闭环的故事（判断力亮点，重点展开）
4. 诚实边界：主动说出"未上线 / 评测集仍 18 题 / 正确性维度待补"

**避坑提醒**：

- ❌ 不要孤立写"总分 0.96 分"——0.867→0.96 背后是**口径变更**（补了 reference），被追问"分怎么来的"答不清会反噬
- ✅ 改为"修复评测指标缺陷，使语义权重从失效恢复生效"，重点放在"发现了什么"而非"分数涨了多少"
